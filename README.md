# Stadium Engagement Blueprint

Password-protected deployment for Stadium's Engagement Blueprint tool.

## Deploy to Netlify

1. Push this repo to GitHub
2. Go to netlify.com → Add new site → Import from GitHub
3. Build settings: leave blank (static site)
4. Click Deploy
5. Done — basic auth is handled via `_headers`
